# 术语、双语复核及本地解析升级

## 已实现

全局和本书术语表独立开关、默认关闭，本书译法优先。词库可编辑、导入导出；模型提取由用户主动触发并选择采用。术语只按请求原文命中后附加，相关分段与单元格缓存记录有效译法，无关词库修改不触发重译。

复核窗口保存翻译时的结构对应关系，支持正文和表格单元格编辑、局部重译候选、历史恢复和导出重试。人工修改独立于模型缓存，续跑保留；任务锁和修订版本检测防止窗口覆盖。旧任务只从有效缓存离线恢复对应关系。

本地 MinerU 显示活动日志、耗时与可靠页数，停止清理其进程树。解析复用校验程序、后端、配置、模型文件清单与输出，失败重试使用独立目录。版本无法验证的远程模型不自动复用旧解析。

- 使用本机 Word 隐藏实例将真实译文 DOCX 导出 PDF，逐页检查正文、表格、图片、公式上下标及参考文献后的讨论与附录。

### 真实服务术语对照

使用同一份合成学术样例、已有 DeepSeek 配置和一路并发，各运行一次。全局词条 `recovery period → 恢复期` 被本书 `recovery period → 恢复时段` 覆盖，另指定 `duration → 持续时间`。

| 修订请求数 | 0 | 0 |
| 输入 token 合计 | 1,060 | 1,106 |

术语约束增加 46 个输入 token，未增加翻译请求。本次输出长度差异受模型生成影响，不能据此宣称术语表降低费用；单次样例耗时不能预测长书性能。未配置单价，因此不计算金额。

另实测显式术语建议提取、选中段落重译、采用候选和禁止模型调用时重新导出。候选筛选最初抓取整段短句，实测无可采用结果；修正为在功能词和标点处切开的本地短语后，获得包括氧浓度、恢复期等候选，仍由用户选择采用。

## 验证范围

本轮使用合成学术样例，不上传个人研究材料。自动检查用于结构、数值和术语疑点，不能证明语义完全正确。页码依据可靠结构记录，不模糊匹配；只有 Markdown 或映射不确定时显示未定位。模型清单比较文件路径、大小和修改时间，并非权重文件密码学完整性验证。

Word 沿用原有可读文本和上下标公式能力，本轮未增加原生公式编辑器对象。术语表是用户提供的翻译约束，不保证任何词条适用于所有学科或语境。

不要对共享分支强制推送或删除运行数据。若需永久撤回功能，基于版本历史创建撤销提交并重新验证，而不是重写远端历史。
