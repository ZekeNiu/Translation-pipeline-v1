# 输出目录、质量报告与中文排版

## 使用

更新依赖后重新启动桌面工具。任务目录只保留 `translated.docx`、`translated.md`、`quality_report.html`、`quality_report.md` 和 `_internal`。图片、缓存、原译对应、人工修订、原页摘录与历史版本均在 `_internal`；分享 Markdown/HTML 时请复制整个任务目录。

双击 HTML 报告可对照原文、现译、疑点和建议，并打开原 PDF 页。页码包含封面，与原书印刷页码、译文页码可能不同。跨页表格只有范围可靠时显示范围，不强行猜测每个单元格所在页。

在“复核译文”中：

- “确认保留”记录核对结果；译文或有效术语变化后重新显示疑点。
- “只重译选中项”调用原任务服务生成候选，保存后采用。
- “恢复漏段”针对能可靠确定插入位置的候选；生成候选会调用原任务模型，保存后才插入。无法确定顺序的内容只提示。
- 页眉页脚可选择保留原样式、简洁样式或关闭；预览不应用设置，“应用样式并导出”仅重新排版。
- 导出失败时人工修订仍保存，可用“重新导出”重试。

报告、原页摘录、样式提取和普通重新导出均不调用模型。改译及漏段补译按用户点击调用，记录服务返回的用量，不虚构金额。

## 排版与限制

A4、左右页边距 2.2 厘米；宋体与 Times New Roman，正文 11 磅、1.5 倍行距。标题跟随后文并开启孤行控制。图片保持比例，受版心、页面高度及原始像素尺寸限制；图注与邻接图片关联，不把连续多幅图串成不可分割的大块。

表格保留合并单元格，字号 8.5 磅，普通行尽量不拆开，超长行允许拆分。明确或可靠推断的表头跨页重复。九列以上或估算最小列宽无法放入纵向页的表格使用横向节，随后恢复纵向。较高图像、横向节和图注同页规则仍可能产生留白；不保证最少页数，也不复刻原 PDF 的逐页布局。

能与后续标题准确对应的目录生成 Word 目录域；其他目录保留并注明原页码。首次在 Word 中打开时可能需要更新域（全选后按 F9）。译文页码使用 Word 动态域。

原样式来自原 PDF 重复页边区域：排除页码、避开已知正文，并要求多个页面图像相似。独有封面装饰不会作为重复模板。无法确认安全范围、缺少原 PDF 或源文件变化时退回简洁样式，报告说明原因。装饰为图片，保持原文字和标志，不额外翻译。

遗漏检查只覆盖有结构证据支持的误分类，不等于全书完整性审校；错误 OCR、阅读顺序、图内文字及所有语义漏译不能保证被检测出来。

## 接口与兼容

- `run()` 返回值及成品文件名保持不变；增加可选 `export_options={'header_mode': 'original'|'simple'|'off'}`。CLI 增加 `--header-mode`，不读取 GUI 私人配置。
- `make_docx()` 保留原调用方式，新增可选 `layout`。排版配置不参与翻译缓存键。
- `_internal/layout.json` 标记目录版本；旧任务在锁内先备份至 `_internal/legacy_backup`，再迁移，中断后可继续。
- JSON 报告增加版本化 `issues`；确认记录附于人工修订文件；补译正文单独保存至 `recovered_units.json`，不覆盖模型缓存。

## 回退

代码基线：`rollback/pre-layout-review-20260916`（`d4a5801`）。旧高优先级发布与回退标签保持不变。

1. 保留整个当前任务目录，尤其 `_internal` 中的人工修订与补译。
2. 在单独目录检出回退标签，用 `_internal/legacy_backup` 的副本恢复旧版任务目录。
3. 不让旧版代码直接写入新版目录；旧快照不包含升级后的人工修改。

可以通过新建 `git revert` 提交回退代码，或在独立工作目录检出旧版本。不要强制推送或删除用户数据；从任务快照恢复不需要重新解析 PDF。
